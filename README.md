# hyre-me (하이얼미)

취준생을 위한 AI 기반 자소서 작성 서비스

## 개요

여러 회사에 지원할 때마다 자소서를 다시 쓰는 번거로움을 없앰. 채용공고를 분석하고 사용자의 포트폴리오를 바탕으로 회사별 맞춤형 자소서를 자동 생성하는 서비스

## 설치

```bash
yarn install
```

## 실행

```bash
yarn dev
```

`localhost:3000` 접속

## 빌드

```bash
yarn build
```

## 기술

React 19, Vite, Tailwind CSS, Google GenAI, React Router DOM
